# Pair-partition符号から得た正準論理基底の再現データ

本リポジトリは、岡田昂生・笠井健太「Low-Weight Canonical Logical Bases
from Pair-Partition Codes」の再現用資料です。論文に掲載した符号と追加の
収録したすべての構成について、最終二元検査行列 `HX`, `HZ` と
完全正準論理基底 `LX`, `LZ` を収録しています。

`catalog/codes.csv` が収録符号の一覧です。各 `codes/<code-id>/` には、
圧縮済みの四行列 `matrices.npz`、パラメータとハッシュを記録した
`metadata.json`、利用可能な場合は多項式/QC構成入力 `construction.json`
と厳密距離の検証記録があります。四つの二元行列そのものが、符号と
正準基底を一意に定める共通の完全記述です。

全件のCSS条件、核条件、正準条件、ランク、重み、ハッシュは次で確認できます。

```bash
python3 scripts/verify_all.py
```

ファイル仕様は `docs/format.md`、距離証明記録の範囲は
`docs/distance-certification.md` を参照してください。

論文の付録から移した二元多重CPMの明示例は、
[`codes/f2-multicpm-j3-l8-p128-d22-w9/README.md`](codes/f2-multicpm-j3-l8-p128-d22-w9/README.md)
にまとめています。形式的な族、PP親、対分割、調整小行列、正準化、
固定した `[[1024,256,22]]` 例、および厳密距離の検証記録を掲載しています。
付録表に掲載した `P=52` 例と、従属な4ブロック行表示もカタログに収録しています。

## 最大重なり1/0の追加構成

追加25構成について、二元CSS条件、核条件、完全正準条件、整数重なり恒等行列、ガース、および距離の証明記録を確認しました。最大基底重み39、最大検査重み10の厳密距離15と18の [[1024,256,d]] 符号も含みます。追加の距離11、12、13の構成の最大基底重みは26または27です。論文の表では同じ主要指標を一行にまとめ、カタログでは各構成を区別します。各 `distance/` には、X・Z両側の重みd−1以下の完了記録と、独立に検査した重みdの論理演算子を収録しています。

## 整数重なりが単位行列となる厳密距離20の符号

[P=64の符号](codes/q4-j3-l8-p64-d20-w10-overlap10/README.md)は[[1024,256,20]]で、最大二元検査重み10、正準基底最大重み25/25、整数重なりI_256を持つ。シンボルガース6/6、二元ガース4/4である。余因子と行列式の個別正規化から保存された全行列を再現できる。重み19までの両側48ルートの完了記録と、重み20のX論理演算子を収録した。

P128の追加例は、厳密距離20、基底最大重み27/27、整数支持重なりI512を保証しています。重み19以下の不存在と重み20の非自明演算子により確定しました。完全な行列・構成・上界演算子・段階的な下界の完了記録は[厳密距離20の構成例](codes/q4-j3-l8-p128-d20-w10-overlap10/README.md)に収録しています。
